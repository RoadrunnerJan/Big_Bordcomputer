\doxysubsection{Detailed Description}
I2C interface for DS3231 RTC and time adjustment buttons. 

Manages I2C communication with the DS3231 real-\/time clock and provides button handlers for manual time adjustment functionality.

Update the last execution timestamp for a display to current time.

Records the current system time as the last update time for the specified display. Called after sensor values are successfully read and processed. Only updates if time checks are permitted.
