CHANGELOG v1.0 (01.04.2026) - Initial implementation

◆ init_i2c()

void init_i2c ( void )

Initialize I2C bus and attach RTC and ADC devices.

Initialize I2C bus and attach connected sensors.

Sets up the I2C master bus with configured GPIO pins and clock source, then attaches the DS3231 real-time clock device for time operations. Call this once during system initialization before using I2C functions.

◆ init_time_buttons()

void init_time_buttons ( void )

Initialize time adjustment buttons with callbacks.

Initialize the time adjustment buttons and callbacks.

Configures GPIO-based buttons for hour and minute time adjustments. Registers single-click handlers for time increment and long-press handlers for time decrement. Each button is independently configured with its own debounce timing and active level settings.

Called during system initialization to enable runtime time adjustments and test mode activation via button sequences.

◆ sync_rtc_to_system()

void sync_rtc_to_system ( void )

Read time from DS3231 RTC and synchronize ESP32 system time.

Synchronize system time with RTC DS3231 time.

Reads the current time from the DS3231 real-time clock via I2C, converts from BCD format to standard time structure, and updates the ESP32 system clock. This ensures accurate time after boot.
